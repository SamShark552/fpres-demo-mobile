# FPRES Demo Mobile

Полноценный статический demo-маркетплейс FPRES для GitHub Pages.

## Что работает в демо

- Главная с согласованным premium dark UI
- Популярные игры и реальные обложки Steam CDN
- Каталог с поиском, сортировкой, категориями, платформами и диапазоном цен
- Страницы игр с несколькими предложениями продавцов
- Страницы продавцов
- Корзина на localStorage
- Demo checkout без реального списания
- Генерация демо-ключа после заказа
- Личный кабинет и история последней покупки
- Demo seller dashboard
- Демо-авторизация
- Responsive layout для iPhone / desktop
- Все ключевые кнопки и переходы работают

## Страницы

- index.html

## Важно

Это только фронтенд-прототип. Реальные платежи, выплаты продавцам, аккаунты, PostgreSQL и API в этой версии не подключены.
